# Skriftene

Filene i denne katalogen er ikke laget av Utdanningsnytt. De er delsett (latin og latin-ext)
av tre skrifter som alle er utgitt under SIL Open Font License 1.1
(<https://openfontlicense.org>):

| Skrift | Kilde |
| --- | --- |
| Inter | <https://github.com/rsms/inter> |
| JetBrains Mono | <https://github.com/JetBrains/JetBrainsMono> |
| Source Serif 4 | <https://github.com/adobe-fonts/source-serif> |

Lisensteksten og opphavsrettsmerknaden for hver skrift ligger ved siden av, i `OFL-Inter.txt`,
`OFL-JetBrainsMono.txt` og `OFL-SourceSerif4.txt`, hentet uendret fra repoene over. De skal følge
skriftene når filene deles videre.
